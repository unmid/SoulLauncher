What it actually does

No folders to manage, no Java to hunt down, no loader installers to run by hand.

1

Isolated Spaces

Each Space is one Minecraft version with its own loader, mods, worlds, and settings. A broken 1.8.9 Forge experiment can never touch your Fabric world.

2

Categories that sync themselves

Group Spaces and their in-game servers plus settings stay identical across the group — add a server once, in-game, and every member has it.

3

Soul Client FPS builds

One-click tuned Fabric clients built from public, inspectable mods. Manifest-only releases keep every file auditable.

4

Honest content browser

Modrinth and CurseForge installs resolve files for your exact version and loader — or say plainly that nothing compatible exists.

5

Version honesty

Never a silent "latest". Modpacks pin to your Minecraft version, snapshots are labeled, unsupported rows are marked before you click.

6

Quiet updates

Signed in-app updates. Microsoft sign-in through the official flow, tokens in Windows Credential Manager, offline play supported.

Sync without a sync button

There is deliberately no "manage servers" screen. The game files are the truth; the launcher just keeps every member of a category pointed at the same ones — one shared servers.dat and options.txt per group, linked with OS symlinks (atomic copy fallback where Windows refuses), parsed as real NBT so a corrupt write can never poison the group.

Install in two minutes

  1. Download SoulLauncher-Setup.exe from the v1.0.0-beta release and run it.
  2. Create a Space: pick Minecraft, pick software, optionally add content, name it.
  3. Press Play. Java, loaders, and libraries download themselves on first run.
SmartScreen will complain. The beta is not code-signed, so Windows shows "Windows protected your PC". Click More info → Run anyway, or build from source (npm ci && npm run dist) and trust nobody. Full details in the README.
