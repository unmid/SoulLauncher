What it actually does

No folders to manage, no Java to hunt down, no loader installers to run by hand.

Isolated Spaces

Each Space is one Minecraft version with its own loader, mods, worlds, and settings. A broken 1.8.9 Forge experiment never touches your Fabric world.

Categories that sync themselves

Group Spaces that play together. Add a server in-game on one of them, and every member of the category has it. No export, no copy-paste, no settings screen.

One-click client builds

Install the OneClient pack straight from the wizard. The launcher resolves the build that matches your exact Minecraft version.

Honest content browser

Modrinth and CurseForge installs resolve files for your real version and loader, with clear Add and Remove buttons on every row.

No silent latest

When nothing compatible exists for your setup, the launcher says so instead of quietly installing the wrong file.

Quiet by design

Signed in-app updates, Microsoft sign-in through the official flow, offline accounts, and a window that idles in the background instead of eating your RAM.

Sync without a sync button

There is deliberately no manage-servers screen. Each category owns one shared servers.dat and one options.txt. When a Space joins, its files link to the shared copies, so an in-game change is instantly true for the whole group. Writes are parsed as real NBT, so a corrupt file can never poison the group.

Install in two minutes

1

Download

Grab SoulLauncher-Setup.exe from the release page and run it.

2

Create a Space

Pick Minecraft, pick software, add content if you want, name it.

3

Press Play

Java, libraries, and loaders download themselves on first run.

Windows will warn you once

The beta is not code-signed, so SmartScreen shows an unknown-publisher prompt. Choose More info, then Run anyway.

If you would rather trust nobody, build it yourself: npm ci && npm run dist. The full note lives in the README.
